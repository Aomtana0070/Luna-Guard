# Project Overview

## Summary

Luna Guard is a pre-revenue security software project maintained in a public GitHub repository. It consists of an on-demand Windows desktop scanner and quarantine helper, Flutter companion source for Android and iOS, YARA rules, documentation, and automated build/release workflows. A separate public website introduces the project.

The creator, Tanapisit Onsroi, wants to hand the project to a team able to continue its development and is willing to assist with a technical transition. Asking price: **Open to serious offers**; no valuation is asserted.

GitHub stars, release downloads, and contributor activity can change over time. Consult the repository and release pages directly; downloads do not establish unique users or customers.

## Why it is available

The creator would like a team with capacity to carry the project forward. This is a project handover opportunity, not a profitable operating business or a promise of future revenue.

## What a buyer can evaluate

The repository includes application source, dashboard and localization content, YARA rules, mobile source, technical/security documentation, tests, benchmark tooling, and CI build workflows. The exact transferable scope depends on ownership and license review documented in [Licensing and IP](06_LICENSE_AND_IP.md).

## Suggested diligence sequence

1. Review product scope and stated limitations.
2. Build from a clean checkout and run the existing test commands.
3. Review security-sensitive code paths, signing/release controls, and third-party terms.
4. Identify rights owners for the name, logo, artwork, website, rules, and signing identities.
5. Agree in writing on included assets, transition assistance, and any excluded accounts or credentials.
